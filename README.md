# Лабораторна робота №1: Рекурсивні алгоритми та обхід структур даних

Цей репозиторій містить рішення задач для першої лабораторної роботи. Основний фокус зосереджений на використанні рекурсії, роботі з двовимірними масивами та розв'язанні класичних алгоритмічних проблем.

Усі завдання реалізовані на мові **JavaScript (Node.js)**.

## 📋 Опис реалізованих завдань

1. **Генерація перестановок (Комбінаторика):** Використання рекурсії для знаходження всіх можливих унікальних перестановок заданого набору елементів.
2. **Пошук шляху в лабіринті (Maze Pathfinding):**
    - Знаходження будь-якого виходу з лабіринту 6х6.
    - Знаходження **найкоротшого шляху** до виходу з урахуванням кількох можливих маршрутів.
3. **Максимальна сума в трикутнику:** Знаходження шляху з найбільшою сумою від вершини до основи числового трикутника (рух лише вниз-вліво або вниз-вправо).
4. **Задача про найдовший шлях (Longest Path Problem - "Удав"):** Пошук максимальної довжини неперервної лінії на сітці 8х8 із перешкодами (без перетину самої себе). Включає запобіжники для уникнення зависання (NP-складна задача).
5. **Підрахунок кількості островів/озер (Number of Islands):** Знаходження та підрахунок ізольованих скупчень нулів на матриці 10х10.

## 🧠 Використані алгоритми та концепції (Словник термінів)

Під час виконання лабораторної роботи були на практиці застосовані наступні концепції Computer Science:

* **Depth-First Search (DFS / Пошук у глибину):** Алгоритм обходу графа або масиву, який спочатку йде максимально глибоко по одній гілці до самого кінця, і лише потім повертається на крок назад, щоб перевірити інші можливі шляхи.
* **Backtracking (Відкочування стану):** Процес скасування тимчасових змін після того, як гілка рекурсії завершила роботу (наприклад, стирання "слідів" пройденого шляху в лабіринті, щоб інші гілки алгоритму могли пройти через цю ж точку).
* **Pruning (Відсікання гілок):** Алгоритмічна оптимізація, при якій програма зупиняє подальше занурення в рекурсію, якщо розуміє, що цей шлях безперспективний (наприклад, коли кількість кроків уже перевищила знайдений раніше мінімум).
* **Flood Fill (Алгоритм заливки):** Алгоритм, що використовується для визначення площі, з'єднаної з певним вузлом у багатовимірному масиві. Застосовувався для "замальовування" знайдених озер, щоб уникнути їх повторного підрахунку.
* **Base case (Базовий випадок / Умова виходу):** Критично важлива умова на самому початку рекурсивної функції, яка зупиняє подальші виклики (наприклад, перевірка виходу за межі масиву).
* **Call stack (Стек викликів):** Внутрішній механізм рушія, який запам'ятовує послідовність викликів функцій і локальні змінні кожної ітерації, дозволяючи програмі точно знати, куди відкотитися після команди `return`.
* **Early exit (Раннє переривання):** Практика написання коду, коли функція примусово завершує роботу через `return` відразу після виконання ключової умови, уникаючи зайвих обчислень.
* **Brute-force (Метод грубої сили):** Підхід, за якого програма перебирає абсолютно всі можливі варіанти розв'язку.
